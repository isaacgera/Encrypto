Encrypto

User Guide · v1.1.3

Encrypto is a private, locally-encrypted vault for your important details — documents, passwords, card info and secure notes. Everything is encrypted on your own device and unlocked with a single master passphrase. Nothing is ever sent anywhere.

Contents: Getting started · The one rule · Adding & managing entries · Attachments · Reveal & copy · Locking · Backup & restore · Install · Good to know
⚠ The one rule: there is no recovery. Your master passphrase is the only key to your data. If you forget it, your vault becomes permanently unreadable — there is no reset, no backup question, and no backdoor. This is deliberate: it's what keeps your data safe. Write your passphrase down and keep it somewhere safe.

Getting started

  1. First run — create your vault. Choose a master passphrase (a long, memorable phrase works best — length matters more than symbols), confirm it, tick the box to acknowledge there's no recovery, and select Create vault.
  2. Returning — unlock. Enter your passphrase and select Unlock. If it's wrong (or the stored data has been altered), it simply won't open — there's no partial access.

Adding & managing entries

Select + Add to create an entry. Pick a type and the right fields appear:

  • Document — document type, reference/number, expiry, notes (e.g. passport, driving licence, insurance policy).
  • Password — username/email, password, website, notes.
  • Card — cardholder, card number, expiry, CVV, notes.
  • Note — a free-text secure note.

Give it a title and select Save. To edit or delete, tap an entry in the list — the delete button is inside, and asks you to confirm first.

Finding things

Use the search box to filter by title, type, or any field value, and the type chips (All / Documents / Passwords / Cards / Notes) to narrow the list.

Attachments

Any entry can hold files — a scan of a passport, a photo of a card, a PDF policy. In the entry, use 📎 Add file. Each file is encrypted with your vault key, exactly like the rest of your data, and stored on this device only.

  • Preview (👁) opens the file in a new browser tab — images, PDFs and text display; other types offer to download.
  • Download / save (⬇) saves the file (or opens the share sheet on a phone).
  • Remove (🗑) deletes that attachment.
  • Images show a small thumbnail; other files show an icon.

Size limit: 5 MB per file. If an image is larger, Encrypto can compress it to fit (it shows you the before/after size first). Other large files need to be smaller before attaching. Attachments are included in your encrypted backup.

Reveal & copy

Sensitive fields (passwords, card numbers, CVV, notes) are masked by default. Use the eye button to reveal a value, and the clipboard button to copy it.

Copied values auto-clear from the clipboard after 30 seconds, so they don't linger. On phones the native share/copy flow is used where available.

Locking

  • Auto-lock on idle: the vault locks itself after 5 minutes without activity. A small countdown in the top bar shows when it will lock.
  • Lock on leave: it also locks the moment you switch tabs or send the app to the background.
  • Lock now: the Lock button locks immediately.

When locked, your data is encrypted and the key is wiped from memory — you'll need your passphrase to get back in.

Backup & restore

Open the ⋯ menu (top right) for backup options.

  • Export encrypted backup — downloads a .json file that is itself encrypted. It's useless to anyone without your passphrase, so it's safe to store.
  • Import backup — restores from a backup file. This replaces the vault currently on the device, and you'll unlock it with that backup's passphrase.
  • Delete vault — permanently removes the vault from this device (asks twice).
Back up regularly. Your vault lives only in this browser on this device. Clearing your browser data, or losing the device, will erase it — an export is your safety net.

Install it (optional)

Encrypto is a Progressive Web App, so you can install it to your home screen or desktop and use it like a normal app, fully offline.

  • iPhone/iPad (Safari): Share → Add to Home Screen.
  • Android (Chrome): menu → Install app / Add to Home screen.
  • Desktop (Chrome/Edge): the install icon in the address bar.

Good to know

  • Zero network. Encrypto never sends your data anywhere — no accounts, no servers, no tracking. It works entirely offline.
  • Strong, standard crypto. Your passphrase derives an encryption key (PBKDF2-SHA256), and entries are sealed with AES-GCM using the browser's built-in Web Crypto. The stored data is only ciphertext.
  • Not a hardware vault. Encrypto protects your data at rest. It can't protect against a compromised device (malware) or a weak/guessed passphrase. Choose a strong passphrase and keep your device secure.
  • Secure context needed. Encrypto must be opened over HTTPS (or localhost). It won't run with weakened cryptography.
